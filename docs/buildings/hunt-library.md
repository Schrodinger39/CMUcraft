# Hunt Library — first exterior proposals

**Start small:** suggest one repeating window-and-fin section. You do not need to
rebuild the whole library or reserve the building to post a proposal.

[Download the shared trial pack](https://github.com/Schrodinger39/CMUcraft/releases/tag/builders-round1)
· [Quick start](../BUILDERS.md) · [Find Hunt tasks](https://github.com/Schrodinger39/CMUcraft/issues/3)

## A useful first contribution

Build a small facade sample in your private trial copy, or mark up a reference photo
with what looks distinctive. Show one screenshot/image and explain what you changed.
Ordinary blocks are welcome; using C&B is optional. The pack still needs C&B installed
to keep the common environment consistent. Leave interior rooms for a later round.

Focus on silver vertical fins, recessed glazing and the spacing between windows.
Keep the building recognizable before adding tiny details. Roof and entrance ideas
are welcome, but unknown dimensions should be labeled estimates.

The trial world uses the rough campus model as context. Do not mistake its current
window layout, height or materials for instructions to copy them. No verified total
height is supplied by the building reference packet. Link third-party photos rather
than uploading images you do not have permission to share.

## Boundaries and ownership

The trial square is X 400..479, Z 720..799, all heights. It intersects Baker Hall and
College of Fine Arts reference outlines. Keep neighbors, paths and terrain intact.
A square border is a technical limit, not permission to rebuild everything inside it.

Anyone can try a design independently. For the main building, one coordinator will
maintain the accepted save; comment in the Hunt task if you want that role. Multiple
proposals are welcome but cannot be automatically merged inside the same chunks.
The first round is about choosing a facade direction, not accepting a finished replica.
