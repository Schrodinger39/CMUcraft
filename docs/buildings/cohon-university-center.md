# Cohon University Center (CUC) — first exterior proposals

**Start small:** identify one entrance or distinguish one part of the building's
exterior. A photo/reference contribution is useful even if you do not play Minecraft.

[Download the shared trial pack](https://github.com/Schrodinger39/CMUcraft/releases/tag/builders-round1)
· [Quick start](../BUILDERS.md) · [Find CUC tasks](https://github.com/Schrodinger39/CMUcraft/issues/4)

## A useful first contribution

Pick one entrance or facade. Provide a reference link or your own photo, identify the
side/location, and describe two or three details the rough Minecraft model misses.
Alternatively, build a small exterior sample in your private copy and post a screenshot.
You do not need to claim the whole building. Interiors are outside this first round.

The existing reference notes call for gray masonry, tan details, mixed low-slope
roofs and a distinct 2016 addition. Help confirm which part is which before proposing
one uniform height or repeating the same windows across the entire footprint.
Ordinary blocks are welcome; C&B detailing is optional.

The reference packet flags a footprint comparison for review and does not provide a
verified total height. The trial world's architecture is a placeholder, not an approved
model. A current, identified reference photo is more useful than a guessed dimension.
Link third-party photos rather than redistributing them without permission.

## Boundaries and ownership

The trial square is X 512..687, Z 400..575, all heights. Its reference overlap includes
West Wing and East Campus Garage. Keep these neighbors, paths and terrain intact.
The border is a technical limit, not permission to demolish the whole square.

Anyone can propose a design. A single building coordinator will maintain the accepted
save after scope review. Independent edits inside the same chunks cannot be automatically
combined. This CUC trial world is packaged and storage-checked, but has not yet been
opened in a Minecraft client; you can start with the reference task without installing it.
